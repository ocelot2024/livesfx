## ⚙️ Prerequisites

- Node.js 22+
- pnpm 9+

## 🚀 Installation

```bash
git clone https://github.com/ocelot2024/livesfx.git
cd livesfx
pnpm install
```

## 💻 Usage

```bash
pnpm run dev
```

## ✨ Features

- ✅ Sound effects playback
- ✅ Dual-deck BGM player
- ✅ Project save and export
- ✅ Offline support
- ✅ Remote control via WebRTC
- ✅ Touch-optimized interface
- ✅ Designed for iPad Safari
